# Tài Liệu Thiết Kế & Nhật Ký Học Tập

Thư mục này lưu các ghi chép do chính bạn viết trong quá trình làm dự án. Gợi ý các file nên có:

- `erd.md` (hoặc `erd.png`): Sơ đồ ERD của [Task 0.4](../tasks/week_02/task_04_data_modeling.md). Bạn có thể vẽ bằng dbdiagram.io, draw.io, hoặc viết bằng Mermaid ngay trong file Markdown (GitHub hiển thị được trực tiếp).
- `decisions.md`: Các quyết định thiết kế quan trọng và lý do lựa chọn. Ví dụ: vì sao chọn kích thước chunk và tỷ lệ overlap như vậy, vì sao chọn HNSW thay vì IVFFlat.
- `learning_log.md`: Nhật ký học tập theo tuần: kiến thức mới, lỗi đã gặp và cách bạn giải quyết.
- `git_cheatsheet.md`: Các lệnh Git bạn đã dùng, giải thích bằng lời của bạn, cùng các lỗi đã gặp ([Task 0.0](../tasks/week_01/task_00_git_github_workflow.md)).
